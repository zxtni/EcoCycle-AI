# Five-minute demonstration

| Time | Click path and talking point |
| --- | --- |
| 0:00 | Sign in as the local demo citizen. On Overview, show the lifetime totals and explain that demo records are synthetic. |
| 0:40 | Open Scan waste → Upload photo. Select `backend/vision_assets/demo-plastic.jpg` → Analyze photo. Point to the bounding box and confidence. |
| 1:25 | Open Wrong result? → choose a correction → Save correction. Explain how the original prediction remains available for review. |
| 2:00 | Enter 0.125 kg → Calculate estimate → Save to my impact → My impact. Explain what multiplies the weight and why the rate can vary. |
| 2:45 | Open Center locator → filter Plastic. Explain live listings, distance and the labeled synthetic fallback. |
| 3:15 | Sign out and sign in as the local demo administrator. Open Municipality → choose Synthetic demo → Apply filters. Download PDF and CSV. |
| 4:00 | Change forecast week → Model metrics. Explain MAE, the holdout and synthetic ward allocation. |
| 4:35 | Open Administration → accept or dismiss the correction → inspect the audit log. |
