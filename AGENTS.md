# Project instructions

Run commands from the project root. Use `node scripts/setup.mjs` to install, migrate and seed, `node scripts/dev.mjs` to serve, and `node scripts/check.mjs` for lint, types, unit/API tests and the production bundle. Keep database credentials and generated environments out of Git.

Use typed request models, server-side authorization and versioned migrations. Keep user-facing estimates labeled. Use common CSS tokens, accessible controls and reduced-motion styles. Trace data and models back to their sources. Keep scripts readable enough for a student to explain.

A milestone is done after implementation, passing checks, fixing regressions and a conventional commit. Final acceptance includes the mobile walkthrough, a clean checkout run and a report distinguishing measured results, synthetic inputs and remaining limitations.
